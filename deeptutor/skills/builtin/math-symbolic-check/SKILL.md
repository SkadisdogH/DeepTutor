# 数学符号 / 数值验证

优先用 `math_symbolic` 工具做验证；它跑 sympy，返回符号/数值结果。需要更复杂脚本时才用 `code_execution`。

## 何时使用

- 验证恒等式、化简表达式、解方程/方程组。
- 求导、求极限、级数展开。
- 检查用户证明中的代数/微积分步骤是否正确。
- 数值搜索反例（小整数、特殊值、极端参数）。

## 怎么把数学问题转成可执行请求

- 等式两边分别提交，让工具判断是否相等（不要只提交一边）。
- 微分/积分写明变量与阶数；极限写明变量与趋近点。
- 搜反例时给出参数范围和候选值，让工具做数值扫描。

## 解释结果

- 符号验证成功 ≠ 证明完成：它只能确认代数恒等或局部成立，不能替代逻辑证明。
- 数值反例 = 强否定证据；数值一致只算弱支持证据。
- 把工具结果原样引用到回答里，并说明它证明了什么、没证明什么。

## 示例

用户问「这个恒等式成立吗」：把左右两边分别丢给 `math_symbolic` 做 `simplify(lhs - rhs)`，
若结果为 0 则恒等；否则让工具给出一个反例点。
